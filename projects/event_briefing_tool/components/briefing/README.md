# components/briefing

실제 제품 화면을 구성하는 컴포넌트 폴더입니다.

주요 단계는 아래 순서로 이어집니다.

- `WelcomeStep`
  첫 진입 화면
- `CompanySearchStep`
  회사 검색과 선택
- `WeekSelectorStep`
  주차 선택과 이벤트 로드
- `BriefingStep`
  브리핑 결과 확인

옆에서 받쳐주는 컴포넌트도 같이 들어 있습니다.

- `AppHeader`, `AppSidebar`
  화면 뼈대
- `SummaryBar`, `StepIndicator`
  현재 상태 요약
- `EventCard`
  공시와 뉴스 카드
- `LoadingOverlay`
  비동기 작업 중 표시

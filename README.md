# hipython

Python 학습 기록, 실습 노트, 작은 프로젝트를 포트폴리오용으로 다시 정리한 저장소입니다.

## Repository Layout

- `projects/`
  - 포트폴리오에 바로 보여주기 좋은 앱, 리포트, 대시보드 중심
- `learning/`
  - 주제별 학습 노트북과 실험 코드
  - Python 기초, SQL, Pandas, ML, LLM, FastAPI, Computer Vision, Deep Learning 정리
- `practice/`
  - 연습문제, 스크래치 파일, 실험 산출물
- `archive/`
  - 현재 포트폴리오 메인 흐름에서는 제외한 로컬 자산 및 이전 버전 보관용

## Notes

- 가상환경, 캐시, 체크포인트, 실행 산출물, 로컬 데이터는 `.gitignore`로 분리했습니다.
- 학습용 원본은 최대한 보존하면서 루트 폴더만 깔끔하게 보이도록 재배치했습니다.
